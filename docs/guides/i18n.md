# i18n Error Messages

pyyaml-rs supports **internationalized error messages** — report errors in your preferred language.

## Set Language

```python
import pyyaml_rs

# Set to Chinese
pyyaml_rs.set_language("zh-CN")

# Set to English (default)
pyyaml_rs.set_language("en")
```

## Supported Languages

| Code | Language |
|------|----------|
| `en` | English |
| `zh-CN` | Chinese (Simplified) |

```python
# List all supported languages
print(pyyaml_rs.list_languages())  # ['en', 'zh-CN']
```

## Get Current Language

```python
print(pyyaml_rs.get_language())  # "en" or "zh-CN"
```

## Auto-Detect from Environment

```python
# Detect from locale environment variables
lang = pyyaml_rs.detect_language()
pyyaml_rs.set_language(lang)
```

Checks these environment variables in order:
1. `PYI18N`
2. `LANGUAGE`
3. `LC_ALL`
4. `LC_MESSAGES`
5. `LANG`

## Language Negotiation (BCP 47)

```python
# Match best supported language from user preferences
result = pyyaml_rs.negotiate_language(
    user_locales=["zh-CN", "en", "fr"],
    default="en"
)
print(result)  # "zh-CN" (best match)

# Fallback when no match
result = pyyaml_rs.negotiate_language(
    user_locales=["fr", "de"],
    default="en"
)
print(result)  # "en" (fallback)
```

## Error Messages in Different Languages

```python
# English
pyyaml_rs.set_language("en")
try:
    pyyaml_rs.parse("invalid: [")
except pyyaml_rs.YamlParseError as e:
    print(e)  # "YAML parse error: line 1, column 9: unexpected token..."

# Chinese
pyyaml_rs.set_language("zh-CN")
try:
    pyyaml_rs.parse("invalid: [")
except pyyaml_rs.YamlParseError as e:
    print(e)  # "YAML 解析错误: 第 1 行, 第 9 列: 意外的令牌..."
```

## Recommended Usage

```python
import locale
import pyyaml_rs

# Auto-detect user's preferred language
user_lang = locale.getpreferredlocale()
if user_lang.startswith("zh"):
    pyyaml_rs.set_language("zh-CN")
else:
    pyyaml_rs.set_language("en")
```
