## API 참조

API 참조는 완전한 `pyrs_yaml` 모듈과 그 클래스를 다룹니다：

- [모듈 참조](reference.md) — 모든 내보내기 함수: 파싱, 직렬화, 검증, 스키마 등록 등
- [YamlDocument 클래스](yaml-document.md) — 라운드트립, 편집, 메타데이터 메서드가 있는 파싱된 문서
- [YAML 인스턴스](yaml-instance.md) — 인스턴스별 옵션이 있는 설정 가능한 파서/직렬화기
- [Node 클래스](node.md) — AST 노드 검사 및 수정을 위한 트리 API
- [MergedView 클래스](merged-view.md) — 병합 키 해결 후 문서의 지연 병합 뷰
- [예외](exceptions.md) — 모든 사용자 정의 예외 타입 및 계층 구조도
