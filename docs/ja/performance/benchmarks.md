!!! note "ベンチマーク環境"
    ベンチマークは作者のマシン（Windows 11、Python 3.12）で測定されたものです。実際のパフォーマンスは環境によって異なります。

## 測定方法

- **ツール:** Criterion（Rust）+ `pytest-codspeed`（Python）
- **反復回数:** ベンチマークごと200回（Python）、100回以上のサンプル（Rust）
- **指標:** 中央値時間（Python、ミリ秒）、平均時間（Rust、マイクロ秒）

## 主な知見

1. **pyrs-yamlはあらゆる操作でPyYAMLより一貫して25〜40倍高速**
2. **pyrs-yamlはラウンドトリップ機能を維持しながらruamel.yamlより4〜10倍高速**
3. **Rust側パースは極めて高速** — 小ドキュメントのパースに約1.7 µs
4. **シリアライズは全サイズで高速** — 小ドキュメントのシリアライズに約4.4 µs
5. **高速化の優位性は、ドキュメントが大きくなるほど顕著になる**

## 注記

- ベンチマークは単一マシンで測定；実際の値は環境によって変動する可能性があります
- 相対的な高速化率（×N倍）はハードウェア間で一貫しています
- PyYAMLのベンチマークは `safe_load` / `safe_dump` を使用（同等の安全保証）
- ruamel.yamlのベンチマークはデフォルト設定を使用
