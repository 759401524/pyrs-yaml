!!! note "ベンチマーク環境"
    CodSpeed CI は **シミュレーション**モード（`mode: simulation`）で実行され、実時間ではなく命令数を測定します。以下のミリ秒値は 2026-08-17 に単一マシンで記録したウォールクロック測定であり、CodSpeed の出力ではありません。以降再測定されていません。倍率は目安であり、インタープリタ、ハードウェア、文書によって変動します。

pyrs-yaml のパフォーマンスベンチマーク。CodSpeed のシミュレーション数値は相対トレンドの追跡用であり、以下のウォールクロック表は単一マシンでの過去の測定値です。

## 測定方法

- **ツール:** divan（Rust）+ `pytest-codspeed`（Python）
- **反復:** CI は CodSpeed シミュレーションを実行。Python 表はウォールクロック測定であり、シミュレーション出力ではない
- **指標:** ミリ秒（Python、ウォールクロック）、マイクロ秒（Rust、シミュレーション）

## 主な知見

1. :material-trending-up: **pyrs-yamlはPyYAMLより解析で21〜43倍、シリアライズで55〜177倍高速**
2. :material-trending-up: **pyrs-yamlはラウンドトリップ機能を維持しながらruamel.yamlより解析で48〜100倍、シリアライズで123〜371倍高速**
3. :material-bolt: **Rust側パース**は Python 呼び出しのオーバーヘッドがなく、シミュレーションレグが操作ごとにコストを分解します
4. :material-bolt: **シリアライズ**は同じシミュレーションレグで常にパースコストを下回ります
5. :material-chart-line: **高速化の優位性は、あらゆるドキュメントサイズで一貫している**

## 注記

- Python 表：2026-08-17 に記録したウォールクロック測定値であり、CodSpeed シミュレーションの出力ではありません
- CodSpeed CI はシミュレーションモードで命令数を報告し、相対トレンドの追跡に使います
- 倍率は目安であり、インタープリタ、ハードウェア、文書サイズによって変動します
- PyYAMLのベンチマークは `safe_load` / `safe_dump` を使用（同等の安全保証）
- ruamel.yamlのベンチマークはデフォルト設定を使用
- Python フィクスチャは 95 B / 687 B / 1949 B（`tests/data/yaml_samples.py`）
