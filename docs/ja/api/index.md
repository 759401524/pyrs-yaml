## API リファレンス

API リファレンスは完全な `pyrs_yaml` モジュールとそのクラスをカバーします：

- **モジュールリファレンス** — すべてのエクスポート関数（パース、シリアライズ、検証など）
- **YamlDocument クラス** — ラウンドトリップと編集メソッドを持つパース済み YAML ドキュメント
- **YAML インスタンス** — 設定可能な YAML パーサー/シリアライザーインスタンス
- **Node クラス** — AST ノードを検査・変更するツリー API
- **MergedView クラス** — マージキー解決後のドキュメントの遅延マージビュー
- **例外** — すべてのカスタム例外タイプ
