## API リファレンス

API リファレンスは完全な `pyrs_yaml` モジュールとそのクラスをカバーします：

- [モジュールリファレンス](reference.md) — すべてのエクスポート関数：パース、シリアライズ、検証、スキーマ登録など
- [YamlDocument クラス](yaml-document.md) — ラウンドトリップ、編集、メタデータメソッドを持つパース済みドキュメント
- [YAML インスタンス](yaml-instance.md) — インスタンスごとのオプションを持つ設定可能なパーサー/シリアライザー
- [Node クラス](node.md) — AST ノードを検査・変更するツリー API
- [MergedView クラス](merged-view.md) — マージキー解決後のドキュメントの遅延マージビュー
- [例外](exceptions.md) — すべてのカスタム例外タイプと階層図
