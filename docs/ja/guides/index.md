## ユーザーガイド

ユーザーガイドは 2 つのセクションに分かれています：

### コア

コア YAML 操作 — パース、シリアライズ、ラウンドトリップ、インプレース編集、ストリーム解析。

### 統合

高度な機能 — カスタムスキーマ、プラグイン開発、コミュニティプラグイン、設定管理、Markdown フロントマター、i18n エラーメッセージ、NumPy ndarray サポート。
