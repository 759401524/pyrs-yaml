## API 参考

API 参考覆盖完整的 `pyrs_yaml` 模块及其类：

- **模块参考** — 所有导出的函数（解析、序列化、验证等）
- **YamlDocument 类** — 支持往返和编辑的解析后 YAML 文档
- **YAML 实例** — 可配置的 YAML 解析器/序列化器实例
- **Node 类** — 检查和修改 AST 节点的树 API
- **MergedView 类** — merge 键解析后文档的惰性合并视图
- **异常** — 所有自定义异常类型
